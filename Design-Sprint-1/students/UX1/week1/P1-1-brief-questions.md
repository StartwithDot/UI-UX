||Three brief questions||


## Gap 1

-question : what happens when a user cant verify all the details before final submission ?

-who can answer : KPSC technical support team maybe

-time estimate : 1 day

-design impact : If users cant verify all the info before the final submission we can provide a dedicated review screen displaying a complete summary of all entered details right before the final submit button so users can cross-check everything and ensure it is correct before locking in their application.

## Gap 2

-question : What happens if a person with low vison couldn't understand the site contents using screen readers?

-who can answer : The designing team of the site maybe.

-time estimate : 1 week

-design impact : If users with low vision cannot understand the contents in the site using screen readers we can redesign the entire site following the 10 heuristics and the WCAG 2.2-AA standards so people with disabilities like blindness and low vision can understand.


## Gap 3

-question : What if a complete new applicant enters the site for any info but cannot find the thing he is looking for because of so many contents overlapping and filled reducing the visibility of the important buttons and informations?

-who can answer : the technical and the designing team

-time estimate : two weeks

-design impact : If the new user cant properly navigate the site because of excessive,unwanted and outdated informations we can design the site using the standards and rules mentioned in the gap 2 impact and we can properly divide the content using proper headings and for most important and upcoming events and infos make it bigger and highlighted using colors and text weight and de-emphasize the contents that are least important and also give clear headings for finished events
