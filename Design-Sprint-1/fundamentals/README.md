# Fundamentals

The learning spine of the program. Filed and spot checked, not graded task by task. Each sprint folder has its own `fundamentals/`; session and teardown numbers keep counting across sprints.

| Folder | What goes in it | Cadence |
|---|---|---|
| `drills/` | `UX{n}-log.md`. Ten minutes per session: rebuild one real component from memory, compare, log one line. A new file each sprint; the session count keeps going. | every session, 24 weeks |
| `teardowns/` | `{nn}-{subject}.md`. One product surface pulled apart. Template inside. | weekly |
| `why-sessions/` | `week{nn}-{topic}.md`. The week's fundamentals topic, presented by one designer. | weekly, rotating |
| `explainers/` | One explainer per sprint on a concept you had to teach yourself. | per sprint |
