# Gate Rubric

Applied to a deliverable chosen at random each week. The gate is a checklist, not an opinion.

| Gate | Pass condition | Fails if |
|---|---|---|
| **States** | Every required state is designed, not described: default, empty, loading, partial, error, success, offline, permission denied, zero results, first run, destructive confirm where applicable | Any state is described in a note, or the states matrix is uniform with no reasons for not-applicable |
| **Accessibility** | Every line of `06-accessibility-gate.md` has a measured value or a recorded observation. Screen reader announcement written out verbatim. | Uniform "pass" with no numbers; contrast not measured in every theme; no screen reader run |
| **Evidence** | Every claim about users names a participant, a number, a convention or a heuristic with the user cost | "Users prefer", "users found" with no participant |
| **Craft** (Sprint 5) | System compliance, both widths, both themes, motion with a stated purpose | Local forks without a written reason |

Score each: Pass / Pass with notes / Fail. A fail means the work is not done, however it looks.
